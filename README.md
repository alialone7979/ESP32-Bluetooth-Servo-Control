# ESP32 Bluetooth Servo Control

A simple embedded systems project for controlling an SG90 servo motor wirelessly using an ESP32 and a smartphone via Bluetooth.

## Features

- ESP32-based control
- Bluetooth communication
- SG90 servo motor control
- Smartphone-based operation

## Hardware

- ESP32
- SG90 Servo Motor
- LED
- Resistor
- Breadboard
- Jumper wires
- Smartphone

## Software

- Arduino IDE
- ESP32Servo Library
- Bluetooth Serial Terminal

## How It Works

The ESP32 receives commands from a smartphone via Bluetooth.
Based on the received command, the servo motor moves to the corresponding position.
